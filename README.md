# UCI-Heart-Data-Modelling-and-Analysis
Trained and implemented various models (decision trees, random forest, regression, &amp; Adaboost) in Python using Pandas / Seaborn / Matplotlib / scikit-learn in a Jupyter / Conda environment to clean and analyze medical data from UCI's Cleveland Heart dataset with the goal of predicting heart disease likelihood. 

*I started with a pre-processed dataset from Kaggle but upon initial analysis, it became clear that something was wrong. So I checked for another Kaggle analysis for comparison. Indeed there were differences. To ensure accuracy and avoid reliance on others' mistakes, I downloaded the original raw data, processed it myself, then conducted the analysis, training, and prediction.*

*Initial Kaggle dataset, pre-processed: https://www.kaggle.com/datasets/cherngs/heart-disease-cleveland-uci*

*Supplementary Kaggle dataset for comparison: https://www.kaggle.com/datasets/aavigan/cleveland-clinic-heart-disease-dataset*

*Raw data from UCI: https://archive.ics.uci.edu/dataset/45/heart+disease*
